# Hustle City

A real life simulation. Start in Benin City, hustle your way across Nigeria.

**Engine:** Godot 4 (GDScript) — web + Android
**Time:** 20:1 — one game day = 72 real minutes
**Team:** Javin Ozel (PM) · Kirasa (senior dev, arch + backend) · Agy (frontend)

## Quick start

1. Open `project.godot` in Godot 4.
2. Press F5. Benin City awaits.

## Structure

- `scenes/` — main, ui, city, avatar scenes
- `scripts/` — core, economy, social, city, avatar, network
- `assets/` — models, textures, audio
- `backend/` — authoritative server (accounts, ledger, friends, travel)
- `docs/` — design docs

See [ARCHITECTURE.md](docs/ARCHITECTURE.md) for the full design.
